# SESSION START CHECKLIST — HÁN NGỮ CÙNG BÁCH HỮU

## 30-second recovery

- [ ] Read WORK_STATE.md.
- [ ] Read relevant PROJECT_MEMORY.md.
- [ ] Read relevant DECISION_LOG.md / DATA_CONTRACT.md.
- [ ] Read SKILL.md when this project is being continued after a context break.
- [ ] Inspect the actual target artifact.
- [ ] Check for STALE / CONTRADICTED state.
- [ ] Identify last verified good state.
- [ ] Identify exact next action.
- [ ] Identify do-not-touch.

## First session after installation

If WORK_STATE says REPOSITORY RECONCILIATION REQUIRED:
- [ ] Run RECONCILIATION_PLAN.md completely.
- [ ] Do not remediate unrelated findings.
- [ ] Produce RECONCILIATION_REPORT.md.
- [ ] Update WORK_STATE to the verified baseline.
- [ ] Only then resume product implementation.

## Recovery questions

1. Where did the last session stop?
2. What was the last verified good state?
3. What is the first unfinished action?
4. What failed already?
5. What must not change?
6. What evidence supports the current state?
