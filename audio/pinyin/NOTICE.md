Recordings: **Chen Wang**. Project: **hugolpz/audio-cmn**.

Source: https://github.com/hugolpz/audio-cmn/tree/ff9ed3d0c631195bd2c06f39450f3264c7124040/64k/syllabs

Source revision: `ff9ed3d0c631195bd2c06f39450f3264c7124040`.

The upstream README identifies the syllable recordings as **CC-by-sa**, without specifying a license version. These recordings are distributed with the same upstream license notice. See the retained [upstream README](SOURCE_README.md) for authorship and credits.

1,620 files are used here, covering 405 practice syllables in four tones. Audio bytes are unchanged; filenames were shortened for the lookup table. Upstream `cmn-jv4.mp3` is named `ju4.mp3` here, following standard Pinyin spelling. No speaker voice was synthesized or cloned. These short samples are independent of the Douyin videos.

Project and processing credits in the source include Hugo Lopez / PLIDAM, INALCO, and Nicolas Vion. Vietnamese teaching notes and website code are separate from these recordings.

Thông tin tác giả, nguồn, ánh xạ tệp và phiếu tự kiểm tra của giáo viên nằm trong thư mục `admin/` của mã nguồn. Thông báo này được giữ cùng tệp âm thanh khi phân phối.
