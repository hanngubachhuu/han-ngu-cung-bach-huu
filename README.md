# Hán Ngữ Cùng Bạch Hữu

Website học tiếng Trung.

Ba công cụ Hán tự, Từ điển và Đọc hiểu dùng chung dữ liệu giáo trình, đăng nhập và lưu bài với Supabase. Xem [hướng dẫn chạy, dữ liệu và triển khai](docs/STUDY_WORKSPACE.md).

Khu vực tài khoản mới: `tai-khoan.html`; quản trị: `quan-tri.html`. Schema account/Docs đã triển khai và giữ nguyên quyền học; tiến độ phát hành website được ghi trong [kế hoạch phát hành](docs/deployment.md). Đọc [audit hiện trạng](docs/CURRENT_SYSTEM_AUDIT.md), [kiến trúc](docs/architecture.md), [xác thực](docs/auth.md), [phân quyền](docs/authorization.md), [database](docs/database.md), [Google Docs](docs/google-docs.md), [backup và chuyển nền tảng](docs/portability.md).

Chủ tài khoản chưa có Google Cloud project: làm theo [hướng dẫn kết nối Google từ đầu](docs/GOOGLE_SETUP_FOR_OWNER.md). Chỉ nhập OAuth secrets vào môi trường máy chủ; không gửi qua chat hoặc commit vào Git.
